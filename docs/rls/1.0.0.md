## Release 1.0.0 – Changelog Summary

Version 1.0.0 marks the initial public release of the **Symfony Git Installer**, a lightweight PHP-based deployment tool designed to download and manage GitHub repositories directly on a server without requiring Git. Inspired by Composer-like workflows, it simplifies deployment and update processes for Symfony and other PHP applications.

* **Core Deployment Tool**
  Introduces a lightweight installer for downloading and extracting GitHub repositories (branches or tags) directly to a server.
  Eliminates the need for Git on production systems.

* **GitHub API Integration**
  Supports downloading repository archives via the GitHub API.
  Enables usage with both public and private repositories through optional GitHub tokens.

* **Self-Update Mechanism**
  Built-in ability to update the installer itself from the source repository.
  Ensures long-term maintainability without manual file replacement.

* **Environment Management**
  Provides direct editing of `.env.local` configuration files.
  Simplifies management of environment variables such as `APP_ENV` and database connections.

* **Symfony Integration**
  Includes support for checking Doctrine migration status, executing migrations, and clearing cache.
  Allows basic application lifecycle management directly from the installer UI.

* **Security Features**
  Optional password protection for installer access.
  Supports additional hardening via server-level protections (e.g., `.htaccess`).

* **Selective File Handling**
  Includes configurable exclusion lists for folders and files (e.g., `.git`, `node_modules`).
  Provides whitelist functionality to preserve critical files like `.env.local` during updates.

* **Automated Cleanup Process**
  Automatically cleans the target directory before installing updates.
  Prevents conflicts with outdated or leftover files.

* **Flexible Configuration System**
  Centralized configuration via `config.php`.
  Allows customization of repository source, installation paths, authentication, and UI behavior.

* **Multi-Language Support**
  Built-in support for multiple UI languages (e.g., English, German, French, Spanish, and more).
  Enables easy localization through the `lang` directory.

* **Simple Installation Workflow**
  Designed for quick setup by copying files to a server and configuring a single file.
  Accessible via browser without requiring CLI tools.

**Compatibility**: Initial release
